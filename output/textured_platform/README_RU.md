# Текстурированная платформа

- `platform_textured.glb` — готовая модель: геометрия, UV, PBR-материал и текстура упакованы в один файл.
- `platform_textured.gltf` — тот же результат в текстовом glTF для отладки/редактирования; данные также встроены.
- `platform_sandstone_albedo.png` — отдельная бесшовная albedo-текстура 1256×1256.
- `platform_source.fbx` — неизменённая копия исходного FBX.

## Важно

При проверке исходного FBX конвертер обнаружил позиции и нормали, но не обнаружил экспортированного UV-канала (`TEXCOORD_0`). Поэтому для готовой модели была автоматически создана box-projection UV-развёртка: верх и низ проецируются по X/Z, боковые грани — по X/Y или Z/Y в зависимости от нормали.

Материал `Sandstone Platform`: metallic 0.0, roughness 0.82, повтор текстуры включён по обеим осям.
