# Fillaculla — первая локация SFB

`fillaculla.flac` — исходный загруженный файл, без изменений: стерео, 44,1 кГц,
101,151338 секунды. Он заменяет Freefall в небесной локации (0–500 м).
Тема Miny главного меню и Crystal Canyon v2 второй локации сохраняются.

Браузер использует `public/music-demo/fillaculla-sky.ogg` (Vorbis q5) или
`fillaculla-sky.mp3` (192 кбит/с). FLAC не загружается игровым клиентом.
Трек зациклен штатным проигрывателем, работает с паузой, переключателем
музыки и существующим переходом в кристальную локацию. При каждом открытии
или обновлении страницы запрос «Включить звук?» ожидает явного выбора.
До «Да» музыка не запускается; «Нет» сохраняет выключение в настройках.
Нажатие вне окна и Escape не закрывают запрос. После отказа музыку можно
включить обычным переключателем в настройках.

Исходная интегральная громкость — −8,09 LUFS. Постоянное усиление −9,91 dB
приводит игровой файл примерно к −18 LUFS. Дополнительные инструменты,
сжатие динамики, изменение темпа или высоты при экспорте не применяются.

Во время забега плеер плавно меняет темп по скорости шара: при стандартной
базе 10 ед/с — 0,90×, при 30 — 1×, при 70 — 1,10×, при 150 — 1,20×;
верхний предел — 1,25×. Замедление возвращает музыку к 0,90×, включая
SLOW через `timeScale`. Сглаживание проходит около 95% изменения за секунду,
`preservesPitch` сохраняет высоту нот. Пауза и скрытие вкладки замораживают
изменение. Тот же принцип применяется к Crystal Canyon v2; тема Miny в
главном меню всегда остаётся на 1×.

Повторный экспорт из корня репозитория:

```sh
ffmpeg -i music/fillaculla/fillaculla.flac -af volume=-9.91dB -ar 44100 \
  -c:a libvorbis -q:a 5 public/music-demo/fillaculla-sky.ogg
ffmpeg -i music/fillaculla/fillaculla.flac -af volume=-9.91dB -ar 44100 \
  -c:a libmp3lame -b:a 192k public/music-demo/fillaculla-sky.mp3
```
