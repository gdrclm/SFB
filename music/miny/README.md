# Miny — заглавная тема и две дополнительные аранжировки

`public/music-demo/miny-original.mp3` — файл музыканта из чата, без изменений.
Он подключён только к главному меню. OGG — совместимая браузерная копия.
В забеге сохранены прежние треки неба и кристаллов. Музыка запускается после
первого касания/нажатия клавиши; переключатель «Музыка» и скрытие вкладки
останавливают любой из треков. При возвращении в меню оригинал продолжается
с прежнего места. Одновременно с ним игровые треки не воспроизводятся.

Две новые версии НЕ подменяют оригинал и не включаются автоматически в игре.
Прослушивание и скачивание: `/music-demo/miny/`.

## Skyline

95 BPM, 4/4, 56 тактов + хвост, 144,47 секунды. Тёплое электропиано,
пальцевый бас, мягкая перкуссия, подложка и короткие ответы флейты.
4 такта вступления, 48 тактов с исходной записью, 4 такта завершения.
Основной гармонический цикл: C(add9) → Am7 → Fmaj9 → Gsus4(add6).
Оригинал входит на 10,105 секунде, без изменения темпа или высоты.
Фразы разрежаются на паузах исходника и уплотняются в последнем припеве.
Мастеринг: −17 LUFS, ограничение true peak −1,8 dBTP до MP3-кодирования.

## Crystal Drive

128 BPM, 4/4, 64 такта + хвост, 123 секунды. Синтезаторный бас,
стеклянные арпеджио, короткие аккордовые удары и электронные барабаны.
8 тактов вступления, 48 тактов основной части, 8 тактов завершения.
Оригинал входит на 15 секунде; `atempo=128/95` сохраняет высоту тона.
Две разреженные секции возвращают пространство перед ритмическими подъёмами.
Последний припев получает дополнительные шестнадцатые, затем аранжировка
разбирается к финалу. Мастеринг: −16 LUFS, true peak −1,8 dBTP до MP3.

## Пересборка

MIDI-файлы содержат НОВЫЕ партии: keys, bass, drums, pad, answer; темп,
размер и маркеры секций. Отдельных инструментальных дорожек оригинала
в исходном MP3 нет. Для текущих версий используется полный стереомикс.

Рендер воспроизводим локально без сетевых генераторов:

```sh
python3 music/miny/render.py --source public/music-demo/miny-original.mp3 \
  --output public/music-demo --work /tmp/sfb-miny
```

Нужны NumPy/SciPy, libfluidsynth, GM SoundFont TimGM6mb и ffmpeg.
В рабочем каталоге остаются 24-битные WAV-мастеры для дальнейшей обработки.
Публичные версии — стерео MP3, 44,1 кГц, 224 кбит/с.
